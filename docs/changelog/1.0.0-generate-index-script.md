# 1.0.0 — Generate index.html from docs/*.md

Adds `bin/generate-index`, a PHP script that builds `index.html` from the
`docs/*.md` files in a fixed order, producing a unified documentation site.

## What changed

- Added `bin/generate-index` which converts each docs markdown file using the
  `markdown` CLI tool and assembles them into a single `index.html` with a
  nested table of contents and syntax-highlighted code blocks.
- Generated `index.html` from the current docs set.

## Why

The existing `index.html` was hand-maintained and did not reflect the current
set of `docs/*.md` files. The new generator keeps the index in sync with the
docs and documents each Strukt package in a consistent, machine-buildable way.

## Documentation touched

- `docs/changelog/README.md` — new changelog index for the `struktapp.github.io`
  package.
- `docs/changelog/1.0.0-generate-index-script.md` — this change file.
- `index.html` — regenerated from docs.

## Tests added or updated

- None (the generator is run manually; no test suite was added).

## Public API impact

- The `struktapp.github.io` package now has a `bin/generate-index` script.
- `index.html` is generated rather than hand-edited.
